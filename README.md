# 🟢 Slime Rancher Pedia

An unofficial Slime Rancher fan project built while learning frontend development.

A small encyclopedia-style website for exploring slimes, locations and information from the world of Slime Rancher.

[View the website →](https://slimerancherpedia.toonvb.com)

</div>

---

## 📖 About the project

Slime Rancher Pedia was originally created as a frontend development exercise during my **Creative Media & Game Technologies** studies.

The main goal of the project was to practice:

- Flexbox
- Responsive layouts
- Semantic HTML
- CSS structure
- Navigation design
- Content-based page layouts
- Basic responsive UI/UX

Instead of creating a generic exercise page, I decided to build it around **Slime Rancher**.

---

## 🟢 Content

The website currently includes information about several slimes and locations from Slime Rancher.

### Slimes

- Gold Slime
- Pink Slime
- Rock Slime
- Rad Slime

### Locations

- The Lab
- Ogden's Retreat
- Mochi's Manor
- Viktor's Workshop

The project was primarily created as a learning exercise rather than as a complete Slime Rancher wiki.
